Automação começa com arquivos — **ler, processar e escrever** é 90% do trabalho repetitivo que um dev automatiza. Nesta lição você domina o módulo embutido de arquivos do Python, com o padrão `with open()` que a indústria usa.

> **Por que importa?** Relatórios, logs, CSVs, configs — tudo é arquivo. Saber processar arquivos com Python é o primeiro passo de qualquer automação, e o padrão `with` previne o bug clássico de arquivo não fechado.

## O padrão: with open()

```python
# Escrever (modo "w" — sobrescreve)
with open("/tmp/notas.txt", "w") as f:
    f.write("ana 7.5\nbob 5.0\ncarol 8.0\n")

# Ler (modo "r" — padrão)
with open("/tmp/notas.txt") as f:
    for linha in f:
        print(linha.strip())
```

O `with` garante: **o arquivo fecha sozinho** ao sair do bloco — mesmo com erro no meio. Nunca esqueça o arquivo aberto.

## Modos de abertura

| Modo | O que faz |
|---|---|
| `"r"` | Leitura (padrão) |
| `"w"` | Escrita — **sobrescreve** tudo! |
| `"a"` | Adiciona no fim (append) |
| `"x"` | Cria — falha se existir |

## Processando linhas

```python
with open("/tmp/vendas.txt") as f:
    for linha in f:              # itera linha por linha
        vendedor, valor = linha.split()   # "ana 1000" → ["ana", "1000"]
        total += int(valor)
```

O `split()` divide pela linha em partes — o jeito mais comum de processar dados de texto.

## Resumo

- **with open(path, modo) as f**: abre e fecha sozinho
- **"r"** leitura · **"w"** escrita (sobrescreve) · **"a"** append
- **for linha in f**: itera o arquivo linha por linha
- **linha.split()**: divide pelos espaços
- Automação = ler → processar → escrever

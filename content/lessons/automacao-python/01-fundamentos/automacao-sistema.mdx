A automação final: **rodar comandos do sistema** (subprocess) e **trabalhar com datas** (datetime). É assim que scripts de backup, deploy e relatórios automáticos funcionam — Python orquestrando o sistema.

> **Por que importa?** Toda automação real um dia precisa rodar um comando externo (git, docker, scripts do sistema) ou registrar "quando isso rodou". subprocess e datetime fecham o ciclo.

## Rodando comandos com subprocess

```python
import subprocess

resultado = subprocess.run(["echo", "olá mundo"], capture_output=True, text=True)
print(resultado.stdout.strip())   # olá mundo
print(resultado.returncode)       # 0 = sucesso
```

- **capture_output=True**: captura a saída em vez de imprimir
- **text=True**: devolve string (não bytes)
- **returncode**: 0 = sucesso, diferente de 0 = erro

## Trabalhando com datas

```python
from datetime import datetime, timedelta

agora = datetime.now()
amanha = agora + timedelta(days=1)

print(agora.strftime("%d/%m/%Y"))   # 05/08/2026
```

- **datetime.now()**: agora
- **timedelta(days=1)**: diferença — soma/subtrai datas
- **strftime("%d/%m/%Y")**: formata

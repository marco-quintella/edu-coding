**BST (Árvore Binária de Busca)** é a estrutura de dados de entrevista #1: cada nó tem esquerda **menor** e direita **maior** — o que torna a busca **O(log n)** no balanceado. É como o índice de um banco funciona por baixo.

> **Por que importa?** "Implemente uma busca binária em árvore" é pergunta clássica. E entender BST é entender índices de banco (B-tree é a evolução).

## A regra de ouro

```
       50
      /  \
    30    70
   /  \   / \
  20  40 60  80

esquerda < raiz < direita   (sempre, para todo nó)
```

## Inserção e busca

```python
class No:
    def __init__(self, valor):
        self.valor = valor
        self.esq = None
        self.dir = None

def inserir(raiz, valor):
    if raiz is None:
        return No(valor)
    if valor < raiz.valor:
        raiz.esq = inserir(raiz.esq, valor)
    else:
        raiz.dir = inserir(raiz.dir, valor)
    return raiz
```

A busca **descarta metade** a cada passo: menor → esquerda, maior → direita.

## Mínimo e máximo

```python
def minimo(raiz):      # sempre à ESQUERDA até o fim
    while raiz.esq:
        raiz = raiz.esq
    return raiz.valor

def maximo(raiz):      # sempre à DIREITA até o fim
    while raiz.dir:
        raiz = raiz.dir
    return raiz.valor
```

## Resumo

- **BST**: esquerda < raiz < direita (sempre)
- **Busca O(log n)** no balanceado — descarta metade por passo
- **Mínimo**: sempre à esquerda · **Máximo**: sempre à direita
- Inserção em ordem crescente → desbalanceia (vira lista)
- Base dos índices de banco (B-tree)

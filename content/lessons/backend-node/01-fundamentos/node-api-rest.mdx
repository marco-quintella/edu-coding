Uma **API REST** é um servidor que expõe dados via URLs (`/usuarios`, `/produtos`) e métodos HTTP (GET, POST). Nesta lição você constrói uma API de verdade: listas, busca por id e parâmetros de URL.

> **Por que importa?** Backend profissional = API REST. Saber expor dados por URL com os status certos é a habilidade central de qualquer vaga backend.

## GET /usuarios — listar

```js
const usuarios = [
  { id: 1, nome: "Ana" },
  { id: 2, nome: "Bob" },
];

const server = http.createServer((req, res) => {
  if (req.url === "/usuarios" && req.method === "GET") {
    res.writeHead(200, { "Content-Type": "application/json" });
    res.end(JSON.stringify(usuarios));   // a lista inteira
  } else {
    res.writeHead(404);
    res.end();
  }
});
```

## GET /usuarios/:id — buscar um

```js
const m = req.url.match(/^\/usuarios\/(\d+)$/);
if (m) {
  const id = Number(m[1]);   // "2" → 2
  const u = usuarios.find((x) => x.id === id);

  if (u) {
    res.writeHead(200);
    res.end(JSON.stringify(u));          // 200 + o usuário
  } else {
    res.writeHead(404);
    res.end(JSON.stringify({ erro: "usuario nao existe" }));
  }
}
```

O `regex` extrai o id da URL; `find` procura no array; 404 se não existe.

## Métodos HTTP

| Método | Ação | Status típico |
|---|---|---|
| GET | ler | 200 |
| POST | criar | 201 |
| PUT | atualizar | 200 |
| DELETE | remover | 200/204 |

## Resumo

- **API REST** = URLs + métodos HTTP + JSON
- **req.method**: GET/POST/... · **req.url**: caminho
- **Regex + find**: extrair id e buscar — o padrão REST
- **404** para recurso inexistente
- **JSON.stringify** para enviar · **JSON.parse** para receber

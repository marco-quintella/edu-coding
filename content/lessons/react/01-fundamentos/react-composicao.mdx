Composição é o **superpoder do React**: apps grandes são feitos de componentes pequenos aninhados. E `children` permite passar "conteúdo" para dentro de um componente — a base de layouts e wrappers.

> **Por que importa?** Layout (Header/Main/Footer), Card, Modal — todos usam children. "O que é composição?" é pergunta de entrevista React garantida.

## children — o conteúdo aninhado

```js
const React = require("react");
const { renderToString } = require("react-dom/server");

function Card({ titulo, children }) {
  return React.createElement(
    "div",
    { className: "card" },
    React.createElement("h3", null, titulo),
    children          // ← o conteúdo que veio de fora
  );
}

const app = React.createElement(
  Card,
  { titulo: "Meu card" },
  React.createElement("p", null, "conteúdo do card")
);
```

**children** é a prop mágica: tudo que você passa como filho do componente.

## Composição — pequeno dentro de grande

```
Pagina
├── Header (titulo)
├── Main
│   └── children (o conteúdo da página)
└── Footer (ano)
```

```js
function Pagina({ titulo, children, ano }) {
  return React.createElement(
    "div",
    null,
    React.createElement(Header, { titulo }),
    React.createElement("main", null, children),
    React.createElement(Footer, { ano })
  );
}
```

## Props com default

```js
function Botao({ label, cor }) {
  const estilo = { backgroundColor: cor || "blue" };   // default
  return React.createElement("button", { style: estilo }, label);
}
```

## Resumo

- **children**: conteúdo aninhado passado de fora
- **Composição**: componentes pequenos → app grande
- **Default props**: `cor || "blue"`
- Layouts = Header/Main/Footer compostos
- Composição > herança no React

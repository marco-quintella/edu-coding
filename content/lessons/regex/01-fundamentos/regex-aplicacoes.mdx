A regex resolve problemas do dia a dia em **uma linha**: dividir texto por múltiplos separadores, extrair domínios de emails, mascarar CPFs. Nesta lição você aplica `re.split` e combina as técnicas em mini-projetos reais.

> **Por que importa?** `split()` do Python só divide por UM separador. `re.split` divide por um PADRÃO — múltiplos separadores de uma vez. É a diferença entre 3 linhas de código e 1.

## Split por padrão

```python
import re

texto = "ana; bob,carol|dan"
partes = re.split(r"[;,|]", texto)
# ['ana', ' bob', 'carol', 'dan']
```

A classe `[;,|]` casa QUALQUER um dos separadores.

## Extraindo domínios

```python
texto = "contato@empresa.com.br e dev@github.com"
dominios = re.findall(r"@([a-z0-9.]+)", texto)
# ['empresa.com.br', 'github.com']
```

O grupo `(...)` captura só a parte depois do `@`.

## Mascarando CPF

```python
cpf = "123.456.789-00"
mascarado = re.sub(r"\d", "*", cpf[:-2]) + cpf[-2:]
# '***.***.***-00' — só os 2 últimos visíveis
```

## Resumo

- **re.split(r"[;,|]", texto)**: divide por qualquer separador da classe
- **findall com grupo**: `r"@([a-z0-9.]+)"` extrai só a parte capturada
- **Máscara de dados**: `\d` → `*` protege CPF/telefone em logs (LGPD)
- Regex transforma 3 linhas de loop em 1 linha

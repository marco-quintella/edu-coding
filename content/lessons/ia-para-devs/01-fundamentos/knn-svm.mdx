# KNN e SVM

Dois algoritmos clássicos de classificação que operam em princípios opostos: o KNN é **baseado em instâncias** (lazy learner), o SVM é **baseado em função** (eager learner).

## KNN — K-Nearest Neighbors

O KNN classifica um novo ponto olhando os **K vizinhos mais próximos** no espaço de features. A classe é a **majoritária** entre esses K.

### Hands-on

Vamos treinar KNN no Iris e ver como diferentes valores de K afetam a acurácia:

<SandboxRunner
  lessonId="b1a39723-5ec9-4892-8f86-d423409f2def"
  initialCode={`from sklearn.neighbors import KNeighborsClassifier
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

for k in [1, 3, 5, 7, 11]:
    model = KNeighborsClassifier(n_neighbors=k).fit(X_train, y_train)
    print(f"K={k:2d} treino={model.score(X_train, y_train):.2%} teste={model.score(X_test, y_test):.2%}")`}
/>

Note como K=1 **overfitta** (100% treino, ~98% teste) e K>5 **underfitta** um pouco (treino cai pra ~96%).

### Parâmetros

- `n_neighbors`: K. K=1 overfitta, K=N underfitta. Comece com `sqrt(N)`.
- `metric`: distância (euclidiana default, manhattan, minkowski)
- `weights`: `uniform` ou `distance` (vizinhos mais próximos pesam mais)

### Quando usar

- Datasets pequenos/médios
- Quando a fronteira de decisão é **irregular**
- Quando você precisa de **explicabilidade** (mostrar os vizinhos)

## SVM — Support Vector Machine

O SVM encontra o **hiperplano** que separe as classes com a **maior margem** possível. Os pontos mais próximos do hiperplano são os **support vectors**.

### Hands-on

SVM com kernel linear e RBF:

<SandboxRunner
  lessonId="b1a39723-5ec9-4892-8f86-d423409f2def"
  initialCode={`from sklearn.svm import SVC
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

for kernel in ['linear', 'rbf', 'poly']:
    model = SVC(kernel=kernel).fit(X_train, y_train)
    print(f"kernel={kernel:6s} treino={model.score(X_train, y_train):.2%} teste={model.score(X_test, y_test):.2%}")`}
/>

### Truque do kernel

Quando os dados não são linearmente separáveis, o SVM usa o **kernel trick**: mapeia os dados para um espaço de maior dimensão onde uma separação linear é possível.

Kernels comuns:

- `linear`: pra dados linearmente separáveis
- `rbf` (default): gaussiano, funciona bem na maioria dos casos
- `poly`: polinomial

### Quando usar

- Datasets de tamanho médio com features em alta dimensão
- Quando a fronteira de decisão é **suave**
- Quando você precisa de **robustez** (SVM é menos propenso a overfitting que árvores)

## Comparação direta

| | KNN | SVM |
|---|---|---|
| Treinamento | Instantâneo | Pode demorar |
| Predição | Lenta (busca K vizinhos) | Rápida |
| Memoria | Alto (guarda todos os dados) | Baixo (só support vectors) |
| Interpretabilidade | Média | Baixa |
| Escalabilidade | Ruim com N grande | Boa |

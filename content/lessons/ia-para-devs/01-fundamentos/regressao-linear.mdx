# Regressão Linear

A regressão linear é o "Hello World" do machine learning supervisionado. Quando você tem um conjunto de pontos `(x, y)` e quer encontrar a reta que melhor representa a relação entre eles, está fazendo regressão linear.

## A fórmula

A equação da reta é `y = mx + b`, onde:

- `m` é o **coeficiente angular** (slope) — o quanto `y` muda quando `x` cresce 1
- `b` é o **intercepto** (intercept) — o valor de `y` quando `x = 0`

O trabalho do algoritmo é encontrar `m` e `b` que minimizam o erro quadrático entre a reta prevista e os dados reais (método dos mínimos quadrados).

## Conceitos importantes

- **Regressão simples**: uma variável independente (`X` 1D)
- **Regressão múltipla**: várias variáveis independentes (`X` 2D)
- **Mínimos quadrados OLS**: método de otimização usado pelo sklearn
- **R² score**: varia de 0 a 1, mede o quanto o modelo explica a variância dos dados

## Próximos passos

A regressão linear é a fundação. Tudo o que vem depois — árvores, SVMs, redes neurais — pode ser visto como extensões dessa ideia: encontrar uma função que mapeia entrada → saída minimizando algum erro.

A regressão linear é o "Hello World" do machine learning supervisionado — e por um bom motivo: ela resolve o problema mais fundamental do ML, **prever um número contínuo a partir de outros números**. Preço de imóvel, temperatura amanhã, faturamento do mês. Todos são problemas de regressão.

Antes de qualquer rede neural, entenda a régua mais simples: uma reta.

## O problema

Você tem um conjunto de pontos `(x, y)` e quer encontrar a **reta que melhor representa** a relação entre eles.

A pergunta central é: **o que significa "melhor"?** E a resposta define todo o campo de regressão.

## A fórmula

A equação de uma reta é `y = mx + b`, onde:

- `m` é o **coeficiente angular** (slope) — o quanto `y` muda quando `x` cresce 1
- `b` é o **intercepto** (intercept) — o valor de `y` quando `x = 0`

O trabalho do algoritmo é encontrar `m` e `b` que **minimizam o erro** entre a reta prevista e os dados reais.

## Por que erro quadrático?

Para cada ponto `(x_i, y_i)`, a reta prevê `ŷ_i = m·x_i + b`. O erro é `y_i - ŷ_i`. Duas escolhas naturais:

- **Erro absoluto** `|y_i - ŷ_i|`: trata todos os erros igualmente
- **Erro quadrático** `(y_i - ŷ_i)²`: **penaliza erros grandes muito mais** (o quadrado amplifica)

Por que o quadrático venceu? Três razões práticas:

1. **Erros grandes são piores que muitos pequenos** — um erro de 10 unidades é 4× pior que um de 5, não 2× (por causa do quadrado). Isso é desejável na maioria dos problemas reais.
2. **A função é diferenciável e convexa** — existe um único mínimo global, e o gradiente aponta sempre para ele. O algoritmo nunca fica preso em "mínimo local".
3. **Tem solução fechada** (fórmula direta, sem iteração) — os mínimos quadrados ordinários (OLS) têm fórmula analítica.

> **Intuição:** o erro quadrático é a "distância" entre o que o modelo prevê e o que aconteceu, elevada ao quadrado para punir erros grosseiros. O modelo ajusta `m` e `b` até essa soma ser a menor possível.

## Mínimos quadrados (OLS)

O sklearn resolve `min Σ(y_i - (m·x_i + b))²` de forma exata. Para regressão simples, a solução tem fórmula fechada:

```python
m = Σ(x_i - x̄)(y_i - ȳ) / Σ(x_i - x̄)²
b = ȳ - m·x̄
```

Não precisa decorar — mas entenda o que ela faz: `m` é a **covariância normalizada** (como `x` e `y` variam juntos, dividido pela variância de `x`), e `b` força a reta a passar pelo **centro de massa** dos dados `(x̄, ȳ)`.

## R² — o quanto o modelo explica

Nem todo modelo é perfeito. Com dados reais, a reta não passa por todos os pontos. O **R² score** mede quanto da variância dos dados o modelo explica:

- `R² = 1` → previsão perfeita (sem ruído)
- `R² = 0` → o modelo não é melhor que "chutar a média"
- `R² < 0` → pior que chutar a média (modelo ruim ou relação não-linear)

## Conceitos importantes

- **Regressão simples**: uma variável independente (`X` 1D)
- **Regressão múltipla**: várias variáveis independentes (`X` 2D) — mesma ideia, mais dimensões
- **Mínimos quadrados OLS**: método de otimização usado pelo sklearn
- **R² score**: varia de 0 a 1 (ou menos), mede o quanto o modelo explica a variância
- **Overfitting vs ruído**: com poucos dados, a reta pode "perseguir" o ruído em vez do padrão

O Processamento de Linguagem Natural (NLP) é o campo da IA que lida com texto. E o primeiro insight desconfortável é este: **modelos não entendem palavras — entendem números**. Antes de qualquer modelo entender texto, precisamos transformar palavras em números — e o primeiro passo é a **tokenização**.

> **Intuição:** um LLM não "lê" como você. Ele vê o texto como uma sequência de peças de LEGO chamadas **tokens**, e aprendeu estatisticamente quais sequências de peças costumam vir juntas. A tokenização é o ato de quebrar o texto nessas peças.

## O que é tokenização

Tokenização é dividir um texto em unidades menores (tokens). Pode ser:

- **Palavras**: `"eu amo IA"` → `["eu", "amo", "IA"]`
- **Subpalavras** (BPE): `"tokenização"` → `["token", "ização"]`
- **Caracteres**: `"IA"` → `["I", "A"]`

A escolha do nível importa: palavras criam vocabulários enormes (e quebram com neologismos), caracteres são ineficientes (sequências longas demais), e **subpalavras** (BPE — Byte Pair Encoding) acham o meio termo: palavras comuns viram tokens únicos, palavras raras viram combinações de subpalavras. **É o que todos os LLMs modernos usam** (GPT, Claude, Llama).

## Remoção de stop words

Stop words são palavras de alta frequência sem significado próprio ("eu", "o", "de", "para"). Removê-las reduz ruído:

```python
from sklearn.feature_extraction.text import CountVectorizer

vectorizer = CountVectorizer(stop_words='english')
X = vectorizer.fit_transform(["this is a test of the system"])
print(vectorizer.get_feature_names_out())  # sem 'this', 'is', 'a', 'of', 'the'
```

> **Atenção (pegadinha clássica):** o `stop_words='english'` do sklearn remove apenas palavras **inglesas**. Se seu texto for em português, você precisa passar sua própria lista — ou "o", "de", "para" vão continuar no vocabulário. É um erro comum em projetos brasileiros!

## Stemming

Reduz palavras à raiz: "correndo", "correu", "corrida" → "corr". Usa `NLTK` ou `spaCy`:

```python
from nltk.stem import PorterStemmer

stemmer = PorterStemmer()
print(stemmer.stem("running"))   # run
print(stemmer.stem("studies"))   # studi
```

O stemming é **agressivo** (corta sem pensar na palavra real — "studies" vira "studi"). A alternativa moderna é a **lematização**, que usa o dicionário para reduzir à forma canônica ("studies" → "study").

## Vetorização: o texto vira matriz

Depois de tokenizar, cada documento vira uma **contagem** de tokens. O `CountVectorizer` cria a matriz documentos × palavras, onde cada célula é quantas vezes a palavra aparece no documento.

## Pipeline NLP típica

```python
Texto bruto → limpeza → tokenização → stop words → stemming → vetorização → modelo
```

Cada etapa transforma o texto em algo mais estruturado até virar números que um modelo pode processar.

## A ponte para LLMs

Tokenização, stop words e vetorização são a era "clássica" do NLP. Os LLMs modernos fazem diferente:

- **Tokenizam em subpalavras** (BPE) — nunca encontram palavra "desconhecida"
- **Não removem stop words** — o transformer usa o contexto completo, e o "de" às vezes é essencial ("copo **de** água" ≠ "copo água")
- **Usam embeddings contextuais** — a mesma palavra tem vetor diferente conforme o contexto ("banco" na praça ≠ "banco" financeiro)

Mas sem entender tokenização você não entende **por que o GPT cobra por token** — e por que prompts longos custam mais. É a fundação de tudo.

**Detecção de anomalias** identifica pontos que **fogem do padrão** dos dados — fraude, defeito, intrusão, falha. É aprendizado não supervisionado por natureza: você não sabe de antemão o que é "anômalo".

## Tipos de abordagem

1. **Estatística**: desvios do z-score, distribuições (Gaussian, Poisson)
2. **Distância**: pontos distantes dos vizinhos (LOF, DBSCAN)
3. **Modelos**: Isolation Forest, One-Class SVM, autoencoders
4. **Séries temporais**: mudanças de padrão ao longo do tempo

## Método estatístico — z-score

```python
import numpy as np

dados = np.array([10, 12, 11, 13, 12, 11, 58, 12, 10])
media = dados.mean()
desvio = dados.std()

# z-score > 3 => anomalia
z = np.abs((dados - media) / desvio)
print("anomalias por z-score:", dados[z > 3])
```

## LOF — Local Outlier Factor

Detecta pontos com densidade local muito menor que a dos vizinhos — bom para dados com clusters de densidades diferentes.

```python
from sklearn.neighbors import LocalOutlierFactor

model = LocalOutlierFactor(n_neighbors=20, contamination=0.05)
labels = model.fit_predict(X)
```

## Quando usar cada um

| Método | Uso |
|---|---|
| z-score | Dados 1D, distribuição aproximadamente normal |
| Isolation Forest | Multidimensional, rápido, bom default |
| LOF | Dados com densidade variável |
| One-Class SVM | Fronteira bem definida, kernel |
| Autoencoder | Dados complexos (imagens, logs), precisa treinar |

## Aplicações

- **Fraude financeira**: transações atípicas
- **Segurança**: intrusão em redes, logins suspeitos
- **Manufatura**: defeitos de qualidade
- **Ops**: picos de erro, latência anômala
- **Saúde**: sinais vitais fora do padrão

## Cuidados

- **Threshold importa** — contamination/false positives são trade-off
- Anomalias raras → métricas além de acurácia (precision@k, AUC)
- **Concept drift**: o "normal" muda com o tempo → re-treinar
- Valide com dados rotulados sempre que possível

Sistemas de IA processam **dados pessoais** — e no Brasil isso é regulado pela **LGPD (Lei Geral de Proteção de Dados)**. Ignorar compliance não é só risco ético, é risco legal: multas de até **2% do faturamento** e sanções da ANPD.

> **Intuição:** a LGPD não é um obstáculo ao ML — é um **padrão de engenharia**. "Minimização de dados" não é só lei, é boa arquitetura: menos dados = menos superfície de ataque = menos custo de armazenamento = menos responsabilidade.

## O que a LGPD protege

**Dados pessoais**: qualquer informação que identifique uma pessoa (nome, CPF, email, IP, localização, biometria...).

**Dados sensíveis** (proteção reforçada): raça, religião, saúde, biometria, orientação sexual.

## Princípios-chave

1. **Finalidade** — coletar só para propósitos legítimos e específicos
2. **Necessidade** — mínimo de dados necessário
3. **Consentimento** — base legal explícita (ou legítimo interesse)
4. **Transparência** — informar como os dados são usados
5. **Segurança** — proteger contra vazamento
6. **Direitos do titular** — acesso, correção, portabilidade, exclusão

## Exercício 2: logs sem dados pessoais

Logs são onde dados pessoais vazam com mais frequência — um `logger.info(f"user {email} ...")` e o CPF/email inteiro está no arquivo. A prática correta: **IDs opacos** (hash irreversível).

## LGPD × IA na prática

### Treinamento
- **Anonimização/pseudonimização** antes de treinar
- **Avaliação de impacto** (RIPD) para dados sensíveis
- Base legal documentada para cada dataset

### Inferência
- Retenção mínima de inputs/outputs
- Logs sem dados pessoais (IDs opacos — você acabou de implementar)
- Direito de explicação das decisões automatizadas

### Deploy
- Contratos com provedores (DPA) — inclusive provedores de LLM
- Processamento regional quando exigido
- Deleção sob demanda (direito ao esquecimento)

## Checklist de compliance para apps de IA

- [ ] Mapa de dados: o que coleta, onde armazena, quem acessa
- [ ] Base legal para cada finalidade
- [ ] Consentimento claro (não em letra miúda)
- [ ] TTL/retenção definida para inputs e logs
- [ ] Procedimento de exclusão a pedido do titular
- [ ] Incidentes: notificação ANPD em 72h

## Provedores de LLM e LGPD

- OpenAI/Anthropic/Google: check se os dados são usados para treino (API = não, por padrão)
- **BYOK** (chave do aluno) transfere a responsabilidade — documente isso
- Em ambientes regulados: modelos self-hosted ou regionais

> **Regra de ouro**: se você não precisa do dado para a tarefa, não colete. A melhor proteção de dados é não ter o dado.

**Sliding Window** é o padrão para problemas de **subarray contíguo**: em vez de recomputar tudo a cada passo, a janela desliza — adiciona um elemento da direita, remove um da esquerda. O(n) em vez de O(n²).

> **Por que importa?** "Maior soma de subarray de tamanho k", "subarray mais longo com soma ≤ k" — clássicos de entrevista. E o padrão é elegante: cada elemento entra/sai da janela uma única vez.

## A ideia

```
Janela de tamanho 3 deslizando:
[2, 1, 5, 1, 3, 2]
[2, 1, 5] → soma 8
   [1, 5, 1] → soma 8 - 2 + 1 = 7   (remove 2, adiciona 1)
      [5, 1, 3] → soma 9
```

**Atualização incremental:** `soma += nums[i] - nums[i - k]` — O(1) por passo.

## Maior soma de janela k

```python
def maior_soma(nums, k):
    soma_atual = sum(nums[:k])
    maior = soma_atual
    for i in range(k, len(nums)):
        soma_atual += nums[i] - nums[i - k]
        maior = max(maior, soma_atual)
    return maior

print(maior_soma([2, 1, 5, 1, 3, 2], 3))   # 9
```

## Janela dinâmica (tamanho variável)

```python
def mais_longo(nums, k):
    esq = 0
    soma = 0
    melhor = 0
    for dir_ in range(len(nums)):
        soma += nums[dir_]              # expande
        while soma > k:
            soma -= nums[esq]           # encolhe
            esq += 1
        melhor = max(melhor, dir_ - esq + 1)
    return melhor
```

O `while soma > k` encolhe a janela pela esquerda até caber — o tamanho é `dir_ - esq + 1`.

## Resumo

- **Sliding Window**: janela contígua que desliza
- **Fixa**: `soma += nums[i] - nums[i-k]` — O(1) por passo
- **Dinâmica**: `while` encolhe quando estoura o limite
- **Tamanho**: `dir_ - esq + 1`
- O(n) — cada elemento entra/sai uma vez

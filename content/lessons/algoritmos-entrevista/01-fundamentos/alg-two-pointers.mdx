**Two Pointers** é o padrão #1 de entrevista: dois índices — um no início, um no fim — andam em direção um ao outro. É o que transforma problemas O(n²) em O(n). Nesta lição você domina o padrão com inversão e busca de pares.

> **Por que importa?** "Inverta esta string sem array extra", "ache o par que soma alvo" — são perguntas clássicas. E o padrão aparece em inúmeros problemas.

## A ideia

```
esq →                    ← dir
[1, 2, 3, 4, 5]          alvo = 7
 esq                dir  → 1+5=6 (pequeno) → esq avança
     esq            dir  → 2+5=7 ✓
```

Dois ponteiros opostos; cada passo move UM deles — **O(n)** total.

## Inversão in-place

```python
def inverter(s):
    chars = list(s)
    esq, dir_ = 0, len(chars) - 1
    while esq < dir_:
        chars[esq], chars[dir_] = chars[dir_], chars[esq]  # swap
        esq += 1
        dir_ -= 1
    return "".join(chars)

print(inverter("abcde"))   # edcba
```

Sem array novo — os ponteiros trocam os extremos até se encontrar.

## Par que soma alvo

```python
def achar_par(nums, alvo):
    esq, dir_ = 0, len(nums) - 1
    while esq < dir_:
        soma = nums[esq] + nums[dir_]
        if soma == alvo:
            return (nums[esq], nums[dir_])
        elif soma < alvo:
            esq += 1        # soma pequena → aumenta
        else:
            dir_ -= 1       # soma grande → diminui
    return None
```

**Requer lista ordenada** — a ordenação garante que andar esq aumenta a soma e andar dir diminui.

## Resumo

- **Two Pointers**: esq + dir andam em direção um ao outro
- **O(n)**: cada elemento visitado uma vez
- **Swap in-place**: chars[esq], chars[dir] = chars[dir], chars[esq]
- **Par com soma**: lista ordenada — soma pequena → esq; grande → dir
- Padrão #1 de entrevista

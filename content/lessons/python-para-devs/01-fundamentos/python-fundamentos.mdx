## Variáveis e tipos

Python é **dinamicamente tipado**: a variável descobre o tipo sozinha. Você não declara `int x`, escreve `x = 10`.

```python
nome = "Ana"          # str (texto)
idade = 25            # int (inteiro)
altura = 1.68         # float (decimal)
ativo = True          # bool (True/False)
```

**Pegadinha clássica:** `type()` revela o tipo real — use quando o código se comportar estranho:

```python
print(type(nome))    # <class 'str'>
print(type(idade))   # <class 'int'>
```

## Operadores

```python
soma = 10 + 3        # 13
divisao = 10 / 3     # 3.333... (sempre float!)
div_inteira = 10 // 3  # 3 (descarta o resto)
resto = 10 % 3       # 1 (útil p/ par/impar: x % 2)
potencia = 2 ** 3    # 8

# Comparações retornam bool
print(10 > 5)        # True
print(10 == "10")    # False! (int ≠ str)
```

**Pegadinha que derruba iniciantes:** `10 / 3` devolve `3.333...`, não `3`. Se você precisa de inteiro, use `//`.

## Condicionais

```python
idade = 17

if idade >= 18:
    print("pode votar")
elif idade >= 16:
    print("voto opcional")
else:
    print("não vota")
```

A indentação **é a sintaxe** — 4 espaços, nada de chaves. O bloco `elif` encadeia condições.

## Loops

### for — repetir sobre uma sequência

```python
for i in range(5):        # 0, 1, 2, 3, 4
    print(i)

for fruta in ["maça", "banana", "uva"]:
    print(fruta)
```

### while — repetir enquanto condição

```python
tentativas = 0
while tentativas < 3:
    print(f"tentativa {tentativas + 1}")
    tentativas += 1       # SEM isso: loop infinito!
```

> **Pegadinha #1:** esquecer o `+= 1` no while = loop infinito (o navegador trava).
> **Pegadinha #2:** `range(5)` vai de 0 a 4 — o fim é exclusivo.

## F-strings (a forma certa de formatar)

```python
nome = "Ana"
idade = 25
print(f"{nome} tem {idade} anos")   # Ana tem 25 anos
print(f"{idade * 2}")               # expressões funcionam
```

Sempre use f-strings em vez de concatenação com `+` — mais legível e sem erro de tipo.

## Resumo

- **Tipos**: str, int, float, bool — descobertos automaticamente
- **Operadores**: `/` float, `//` inteiro, `%` resto, `**` potência
- **if/elif/else**: indentação define o bloco
- **for** (sequência) e **while** (condição) — cuidado com loop infinito
- **f-strings**: formatação legível com expressões

Dados brutos são linhas soltas — **groupby transforma linhas em grupos** e responde "por vendedor", "por cidade", "por mês". É a operação que mais aparece em análise real de dados.

> **Por que importa?** "Qual vendedor vende mais?" "Qual cidade gasta mais?" — toda pergunta de negócio é um groupby. E em entrevistas, groupby é o teste clássico de pandas.

## Filtrando linhas

```python
import pandas as pd

notas = pd.DataFrame({
    "aluno": ["ana", "bob", "carol", "dan", "eva"],
    "nota": [7.5, 5.0, 8.0, 6.5, 9.0],
})

aprovados = notas[notas["nota"] >= 7]   # filtro booleano
```

`notas["nota"] >= 7` cria uma máscara (True/False por linha) — o DataFrame filtra as True.

## Agrupando com groupby

```python
vendas = pd.DataFrame({
    "vendedor": ["ana", "bob", "ana", "carol", "bob", "ana"],
    "mes": ["jan", "jan", "fev", "jan", "fev", "mar"],
    "valor": [3000, 1500, 2500, 2000, 1000, 3500],
})

# Soma por vendedor, do maior para o menor
ranking = vendas.groupby("vendedor")["valor"].sum().sort_values(ascending=False)
# ana: 9000 | bob: 2500 | carol: 2000
```

A leitura: *"agrupe por vendedor, pegue a coluna valor, some"*.

## Múltiplas agregações

```python
por_cidade = clientes.groupby("cidade")["gasto"].agg(["sum", "mean", "count"])
#            sum    mean  count
# SP        3300   1100      3
```

`agg` aplica várias funções de uma vez — total, média e contagem.

## Resumo

- **Filtro**: `df[df["col"] >= x]` — máscara booleana
- **groupby**: `df.groupby("col")["outra"].sum()` — agrupa e agrega
- **sort_values(ascending=False)**: ranking do maior para o menor
- **agg(["sum","mean","count"])**: múltiplas agregações de uma vez
- Toda pergunta "por X?" é um groupby

Ordenar é a operação mais comum em programação — e o Python faz isso com `sorted()` em **O(n log n)**. Esta lição mostra por que o built-in vence qualquer implementação manual, e o que os entrevistadores esperam que você saiba sobre complexidade.

> **Por que importa?** "Ordene esta lista" parece trivial — até você precisar explicar POR QUE sorted() é melhor que escrever o próprio. E a pergunta clássica: "implemente um sort" testa se você entende O(n²) vs O(n log n).

## O built-in: sorted()

```python
dados = [64, 34, 25, 12, 22, 11, 90]

sorted(dados)                 # [11, 12, 22, 25, 34, 64, 90] — NÃO modifica a original
dados.sort()                  # modifica a lista no lugar
sorted(dados, reverse=True)   # do maior para o menor
sorted(["bb", "a", "ccc"], key=len)   # ['a', 'bb', 'ccc'] — por tamanho
```

**O `key=` é o superpoder:** ordenar por qualquer critério sem escrever comparador.

## Bubble sort: por que é O(n²)

```python
def bubble_sort(lista):
    n = len(lista)
    for i in range(n):
        trocou = False
        for j in range(n - 1 - i):
            if lista[j] > lista[j + 1]:
                lista[j], lista[j + 1] = lista[j + 1], lista[j]
                trocou = True
        if not trocou:      # otimização: já ordenado, para cedo
            break
    return lista
```

Dois loops aninhados = **N × N operações** = O(n²). Em 100.000 itens, 10 bilhões de operações — o sorted() faz em milissegundos.

## A tabela que todo dev deve saber

| Algoritmo | Complexidade | Uso |
|---|---|---|
| sorted() / Timsort | O(n log n) | SEMPRE na prática |
| Bubble sort | O(n²) | Nunca (só para aprender) |
| Merge sort | O(n log n) | Entrevistas (dividir e conquistar) |
| Quick sort | O(n log n) médio | Entrevistas |

**Regra de ouro:** use `sorted()`/`.sort()` no código real. Implemente sorts na mão só para aprender/entrevista.

## Resumo

- **sorted()**: O(n log n), não modifica a original; `.sort()` modifica
- **key=**: ordena por qualquer critério (len, campo, lambda)
- **Bubble sort**: O(n²) — entenda para a entrevista, não use na prática
- **Merge de listas ordenadas**: O(n) com dois ponteiros
- Entrevista: saiba dizer a complexidade de qualquer operação

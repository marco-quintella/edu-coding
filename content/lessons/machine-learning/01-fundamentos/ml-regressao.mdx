**Regressão linear** é o modelo mais simples e mais usado: encontrar a **reta** que melhor explica os dados e usar essa reta para prever. Preço × área, salário × anos de estudo — tudo começa aqui.

> **Por que importa?** É a porta de entrada do ML e a base de previsões de negócio. E roda em 3 linhas com scikit-learn.

## O modelo

```python
from sklearn.linear_model import LinearRegression
import numpy as np

X = np.array([[30], [40], [50], [60], [70]])   # área (m²)
y = np.array([150, 200, 250, 300, 350])         # preço (R$ mil)

modelo = LinearRegression()
modelo.fit(X, y)          # APRENDE a reta
```

## Lendo o modelo

```python
modelo.coef_[0]       # 5.0 — cada m² a mais = +R$5 mil
modelo.intercept_     # 0.0 — preço com 0 m²
modelo.predict([[80]])  # 400.0 — previsão para 80 m²
```

**coef** = quanto y muda quando x sobe 1. **intercept** = y quando x é 0. **predict** = usa a reta aprendida.

## A reta aprendida

```
preço = coef × área + intercept
preço = 5 × 80 + 0 = 400
```

## Resumo

- **Regressão linear**: reta que explica os dados
- **fit(X, y)**: aprende · **predict(X)**: prevê
- **coef**: inclinação · **intercept**: y quando x=0
- **preço = coef × x + intercept**
- O ponto de partida do ML

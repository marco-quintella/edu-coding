O **terminal** é o ambiente de trabalho do dev — e Linux roda em ~95% dos servidores do mundo. Nesta lição você roda comandos **reais** no sandbox: navegação, criação de arquivos e a estrutura do sistema.

> **Por que importa?** "Você sabe usar o terminal?" é a base de qualquer vaga backend/DevOps. E os comandos desta lição (pwd, ls, mkdir, find) aparecem TODOS os dias.

## O essencial

```bash
pwd          # onde estou (print working directory)
ls           # o que tem aqui (list)
mkdir -p a/b # cria pasta(s) — -p cria as intermediárias
cd pasta     # entra na pasta
find . -type d   # acha pastas a partir de .
```

## No sandbox (via Python + subprocess)

```python
import subprocess

r = subprocess.run(["pwd"], capture_output=True, text=True)
print(r.stdout.strip())   # / (a raiz do sandbox)
```

O padrão: `subprocess.run([comando, arg1, arg2], ...)` — cada comando é uma lista.

## A estrutura do Linux

```
/          ← raiz (tudo começa daqui)
/bin       ← programas essenciais (bash, ls)
/usr       ← programas de usuário
/home      ← pastas dos usuários
/tmp       ← arquivos temporários
```

## Resumo

- **pwd**: diretório atual · **ls**: listar · **mkdir -p**: criar pastas
- **find -type d**: achar pastas
- **/**: raiz · **~**: home · **/tmp**: temporários
- Comandos = programa + argumentos
- ~95% dos servidores são Linux

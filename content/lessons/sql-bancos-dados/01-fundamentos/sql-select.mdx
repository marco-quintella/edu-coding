SQL é a linguagem dos dados — **todo sistema tem um banco atrás**, e saber consultá-lo é a habilidade mais pedida em vagas de backend e dados. Nesta lição você domina o núcleo: `SELECT`, `WHERE` e `ORDER BY`, rodando **SQLite real dentro do sandbox** (o mesmo SQL do Postgres, MySQL e SQL Server).

> **Por que importa?** Em 2026, SQL aparece em ~70% das vagas de desenvolvimento no Brasil. Você não precisa decorar o banco de cada empresa — precisa saber consultar. E a sintaxe é 95% igual entre bancos.

## O básico: SELECT e FROM

```python
import sqlite3

con = sqlite3.connect(":memory:")   # banco em memória (não persiste)
cur = con.cursor()

# Cria a tabela e insere dados
cur.execute("CREATE TABLE clientes (id INTEGER, nome TEXT, cidade TEXT)")
cur.executemany("INSERT INTO clientes VALUES (?, ?, ?)", [
    (1, "Ana", "SP"), (2, "Bob", "RJ"), (3, "Carol", "SP"), (4, "Dan", "BH"),
])

# SELECT: escolhe colunas | FROM: a tabela
cur.execute("SELECT nome FROM clientes")
for (nome,) in cur.fetchall():
    print(nome)
```

**Leitura:** `SELECT nome` = "quero a coluna nome"; `FROM clientes` = "da tabela clientes".

## WHERE: filtrando linhas

```python
cur.execute("SELECT nome FROM clientes WHERE cidade = 'SP'")
# ↑ só linhas onde cidade é SP

cur.execute("SELECT nome FROM clientes WHERE id >= 3")
# ↑ operadores: =, !=, >, <, >=, <=

cur.execute("SELECT nome FROM clientes WHERE cidade = 'SP' AND id > 1")
# ↑ combina com AND / OR
```

## ORDER BY: ordenando

```python
cur.execute("SELECT nome FROM clientes ORDER BY nome")
# ↑ ordem alfabética (ASC é o padrão)

cur.execute("SELECT nome FROM clientes ORDER BY id DESC")
# ↑ do maior para o menor (DESC = decrescente)
```

**Ordem das cláusulas (decorar!):**
```
SELECT colunas
FROM tabela
WHERE filtro
ORDER BY ordenação
```

## Resumo

- **SELECT** escolhe colunas · **FROM** a tabela
- **WHERE** filtra linhas (=, !=, >, <, >=, <=, AND, OR)
- **ORDER BY** ordena (ASC padrão, DESC decrescente)
- **Ordem fixa**: SELECT → FROM → WHERE → ORDER BY
- Parâmetros `?` evitam SQL injection (nunca concatene strings!)

JSON é a **linguagem franca das APIs** — o formato que todo sistema entende. Nesta lição você domina a conversão entre JSON e Python, que é o primeiro passo de consumir qualquer API do mundo real.

> **Por que importa?** Frontend ↔ backend, microsserviços, integrações — tudo fala JSON. Saber converter e navegar dados JSON é o fundamento de qualquer integração.

## O formato

```json
{
  "id": 1,
  "nome": "Ana Silva",
  "email": "ana@empresa.com",
  "ativo": true
}
```

JSON parece Python — mas não é: `true/false/null` minúsculos, aspas duplas obrigatórias, e tudo é texto.

## Convertendo: dumps e loads

```python
import json

usuario = {
    "id": 1,
    "nome": "Ana Silva",
    "ativo": True,
}

# Python → JSON (serializar)
texto = json.dumps(usuario, ensure_ascii=False)
print(texto)   # {"id": 1, "nome": "Ana Silva", "ativo": true}

# JSON → Python (desserializar)
de_volta = json.loads(texto)
print(de_volta["nome"])   # Ana Silva
print(de_volta["ativo"])  # True (bool Python)
```

**Pegadinha clássica:** JSON `true` vira Python `True` (maiúsculo). `null` vira `None`.

## O formato mais comum: lista de registros

```python
resposta = '[{"id": 1, "nome": "Ana"}, {"id": 2, "nome": "Bob"}]'
dados = json.loads(resposta)   # lista de dicionários

for u in dados:
    print(f"{u['id']}: {u['nome']}")
```

**Isso É uma resposta de API.** Uma lista de dicionários = uma tabela. Sempre que você vê essa estrutura, pensa "dados de API".

## Resumo

- **JSON**: texto universal — true/false/null minúsculos, aspas duplas
- **json.dumps(obj)**: Python → JSON (string)
- **json.loads(texto)**: JSON → Python (dict/list)
- **true→True, false→False, null→None**
- Lista de dicionários = tabela = resposta típica de API

JWT em produção precisa de **expiração** e do fluxo completo de login. Nesta lição você constrói o token com `exp`, verifica assinatura + expiração, e fecha um login simulado — o pacote que todo backend real usa.

> **Por que importa?** Token sem expiração é um risco: roubado, vale para sempre. O fluxo login → token → verificação é o que você implementará em QUALQUER API autenticada.

## Expiração (claim exp)

```python
import time

def criar_token(payload, expira_em=3600):
    payload["exp"] = int(time.time()) + expira_em   # timestamp futuro
    ...

def verificar_token(token):
    ...
    if payload.get("exp", 0) < time.time():
        return None        # expirado → rejeita
    return payload
```

**exp** = timestamp Unix de quando o token morre. Expirou → `None`.

## Verificação completa

```python
def verificar_token(token):
    try:
        header, corpo, sig = token.split(".")
        esperado = b64url(assinar(f"{header}.{corpo}"))
        if not hmac.compare_digest(sig, esperado):
            return None                     # adulterado
        payload = json.loads(decodificar(corpo))
        if payload.get("exp", 0) < time.time():
            return None                     # expirado
        return payload                      # válido!
    except Exception:
        return None
```

**Sempre rejeitar em caso de dúvida** — o `except` devolve `None` para qualquer problema.

## Login com JWT

```python
def login(email, senha):
    armazenado = hashlib.sha256(b"segredo123").hexdigest()
    if hashlib.sha256(senha.encode()).hexdigest() != armazenado:
        return None                          # senha errada
    return criar_token({"sub": "user-1", "email": email})
```

Senha verificada por hash (lição de segurança) → token emitido.

## Segredo em produção

```
NUNCA: no código, no payload, no frontend
SEMPRE: variável de ambiente do servidor (process.env / .env)
```

## Resumo

- **exp**: timestamp de expiração — expirado → rejeita
- **Verificação**: assinatura + expiração (e papel se precisar)
- **Rejeitar em dúvida**: except → None
- **Login**: senha (hash) → token assinado
- **Segredo**: variável de ambiente, nunca no código
